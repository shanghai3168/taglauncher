## Overview

TagLauncher is a macOS utility for organizing and launching installed applications. The app is designed to work locally on your Mac.

## Data Collection

TagLauncher does not collect personal data from users in the current 7.8.13 build.

The app does not include analytics SDKs, advertising SDKs, tracking SDKs, crash reporting SDKs, or third-party telemetry SDKs in the current 7.8.13 build.

## Local Data

TagLauncher stores preferences and launcher configuration locally on your Mac, including:

- App preferences.
- Tag and category configuration.
- Imported or exported category files selected by the user.

TagLauncher scans installed applications locally to build its launcher index. This scan is used only to display and search apps on the user's Mac.

## Network Use

The current 7.8.13 build does not perform background network API calls. Help, support, or release links may open in the user's browser only after user action.

## User-Selected Files

Import and export features use standard macOS file panels. TagLauncher accesses only files selected by the user for those actions.

## Tracking

TagLauncher does not track users across apps or websites.
