# App Review Notes

TagLauncher is a macOS utility for organizing installed applications into visual tag groups and launching them from a keyboard-accessible app grid.

No demo account is required.

## 7.8.14 Specific Note

Version 7.8.14 improves discovery of Apple system applications that live under `/System/Library/CoreServices/Applications`, including Keychain Access. These apps are scanned locally and become searchable by English name, localized display name, and pinyin candidates when available.
