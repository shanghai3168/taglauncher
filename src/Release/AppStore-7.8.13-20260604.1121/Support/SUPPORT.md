## Getting Started

1. Launch TagLauncher.
2. Press `Option-Shift-Space` to open the app grid.
3. Press `Space` while the app grid is visible to open Quick Search.
4. Use Settings to customize icon size, tag display, hotkeys, and layout.

## Troubleshooting

If a newly installed app does not appear immediately:

1. Open App Grid or Quick Search again.
2. TagLauncher 7.8.13 checks standard application folder changes when these views open.
3. If the app is installed outside standard application folders, move it to `/Applications` or `~/Applications`.

If hotkeys do not work:

1. Check macOS System Settings permissions.
2. Confirm another app is not using the same shortcut.
3. Restart TagLauncher.
