## Basic Usage

- Press `Option-Shift-Space` to show the TagLauncher app grid.
- Press `Space` while the app grid is visible to open Quick Search.
- Press `Escape` once to close Quick Search.
- Press `Escape` again to close the app grid.
- Open Settings from the menu bar or with `Command-Comma`.

## Common Questions

### TagLauncher does not open with the shortcut

Another app, input method, or macOS shortcut may already be using the same key combination. Open TagLauncher settings and check the shortcut status.

### Quick Search does not appear

Open the app grid first, then press `Space`. If a modal dialog or editing state is active, close it and try again.

### The app grid appears on the wrong display

TagLauncher is designed to follow the current pointer display. Move the pointer to the target display and open the app grid again.

### Import or export cannot access a file

Use the macOS file panel shown by TagLauncher. App Store builds use sandboxed, user-selected file access.

### Login at launch is unavailable

In App Store sandboxed builds, login-at-launch support may be unavailable if the old LaunchAgent approach is disabled. This is expected until an App Store-safe login item implementation is added.
