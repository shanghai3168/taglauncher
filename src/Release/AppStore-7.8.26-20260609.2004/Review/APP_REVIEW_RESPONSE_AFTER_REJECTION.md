App purpose and target audience:
TagLauncher is a macOS utility for users who have many installed apps and want a faster, calmer way to organize and launch them. It solves the problem of hunting through Launchpad pages or one-folder-only app organization by providing a keyboard-accessible app grid, multi-tag organization, searchable app notes, and local layout backup.

How to access the main features:
1. Launch TagLauncher.
2. Press Option + Shift + Space to open the App Grid.
3. Use the tag list to browse installed apps by category.
4. Press Space while the App Grid is open, or use Fn + Space if configured, to open Quick Search.
5. Search by app name, tag, or note.
6. Open Settings from the menu bar or with Command + Comma.
7. Use Settings > Data to export or import the local layout as JSON.

No demo account is required. TagLauncher does not include account registration, login, account deletion, paid content, in-app purchases, subscriptions, or user-generated content.

External services, tools, or platforms:
TagLauncher does not use external services for its core functionality. App indexing, tags, notes, preferences, and layout data are processed and stored locally on the user's Mac. The app does not include ads or analytics SDKs. If the user opens Help, the app may open or download the localized help PDF from public GitHub Releases; this is documentation only and is not required for core functionality.

Regional differences:
TagLauncher operates consistently in all countries and regions. The app UI is localized, but the core feature set is the same across regions.

Third-party or protected materials:
TagLauncher reads and displays the names and icons of apps installed on the user's own Mac so the user can organize and launch those apps. The app does not bundle, sell, or distribute third-party media content. Any third-party app icons shown in the app are local app icons from apps already installed on the user's device and are used only for launcher functionality.

Privacy and permissions:
TagLauncher does not collect personal data, does not track users, and does not use analytics SDKs. Tags, notes, preferences, and layout data remain on the user's Mac. The app does not request access to location, contacts, camera, microphone, photos, or App Tracking Transparency. For JSON import/export, the user explicitly selects files through the system file picker.
