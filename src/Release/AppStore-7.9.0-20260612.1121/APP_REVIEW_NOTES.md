# App Review Notes

## English

TagLauncher is a local macOS utility for organizing and launching installed apps by tag. No account or demo login is required.

How to test:

1. Launch TagLauncher.
2. Open the App Grid from the menu bar icon or press Option-Shift-Space.
3. Use Quick Search from the grid by pressing Space.
4. Create or use a tag group, then drag an app icon within the same group to change the display order.
5. Open Settings > Data to export or import the local category layout.

Version 7.9.0 adds manual app ordering inside each tag group. The order is stored locally as part of the category layout. The app does not collect user data and does not use analytics, ads, tracking, accounts, or cloud sync.

If the Dock icon is hidden, the menu bar icon remains available. The Dock visibility setting can be changed in Settings > General.

## Simplified Chinese

TagLauncher 是一个本地 macOS 工具，用于按标签整理和启动已安装的应用。不需要账号或演示登录。

测试方式：

1. 启动 TagLauncher。
2. 点击菜单栏图标打开 App Grid，或按 Option-Shift-Space。
3. 在 App Grid 中按 Space 打开 Quick Search。
4. 创建或使用一个标签分组，在同一个分组内拖动应用图标即可调整显示顺序。
5. 打开 Settings > Data，可以导出或导入本地分类布局。

版本 7.9.0 新增标签分组内的应用手动排序。排序数据作为本地分类布局的一部分保存。本应用不收集用户数据，不包含分析、广告、追踪、账号或云同步。

如果 Dock 图标被隐藏，菜单栏图标仍可使用。Dock 显示设置可在 Settings > General 中调整。
