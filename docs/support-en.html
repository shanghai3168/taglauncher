FAQ

App Grid stays on a loading spinner?

Update to TagLauncher 7.8.15 or later. If it still happens, quit TagLauncher completely and open it again. You can also check Settings → Data to make sure the layout file is not damaged, then restore from a backup JSON if needed.

How do I back up categories and layouts?

Open Settings → Data → Export Categories and Layout, then save the JSON file. Use Import to restore it after reinstalling or moving to another Mac.

Can one app belong to multiple tags?

Yes. This is one of the main differences between TagLauncher and Launchpad's folder model.

Does TagLauncher upload my data to the cloud?

No. Categories, tags, and notes stay on your Mac. See the Privacy Policy.
