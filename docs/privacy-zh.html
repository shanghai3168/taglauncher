隐私政策

生效日期：2026 年 6 月 5 日

应用名称：TagLauncher（macOS）

开发者：Hainan Wanxing Technology Co., Ltd.（海南万兴科技有限公司）

概要

TagLauncher 是一款在 Mac 上整理与启动应用的工具。 当前版本（7.8.x）在您的设备本地运行， 不会收集个人数据，也不会将您的启动器分类数据上传至我们的服务器。

保存在您 Mac 上的数据

  • 应用偏好设置（快捷键、外观、语言、Dock 显示等）。
  • 标签名称、颜色、排序，以及应用与标签的关联关系。
  • 您在 TagLauncher 中为应用填写的用途备忘。
  • 您主动导出的 JSON 备份文件（存放位置由您自行决定）。

应用在本地执行的操作

  • 扫描 Mac 上标准应用目录，建立可搜索的应用索引。
  • 通过 macOS 接口打开您选择的应用程序。
  • 当您在「关于」中打开帮助时，可能从公开的 GitHub Releases 下载对应语言的帮助 PDF（仅对该文件的联网请求）。

当前版本不包含

  • 用户账号或登录。
  • 分析、广告或追踪 SDK。
  • 内置的崩溃上报或第三方遥测 SDK。
  • 出售个人数据。

儿童

TagLauncher 并非面向 13 岁以下儿童，我们也不会故意收集儿童的个人信息。

政策变更

若应用功能或法律要求发生变化，我们可能更新本政策，并修订文首生效日期。
