常见问题 / FAQ

应用网格一直转圈？

请更新到 7.8.15 或更高版本。若仍出现，完全退出 TagLauncher 后重新打开； 或在设置 → 数据中确认布局文件未损坏，必要时从备份 JSON 恢复。

如何备份分类与布局？

设置 → 数据 →「导出分类与布局」，保存 JSON 文件。换机或重装后使用「导入」恢复。

一个应用能属于多个标签吗？

可以。这是 TagLauncher 与 Launchpad 文件夹模型的主要区别之一。

数据会上传到云端吗？

不会。分类、标签与备忘保存在本机。详见 隐私政策。
