在全球，这可能是Mac最好用的应用启动台

不用怀念 macOS 26 Tahoe 上消失的 Launchpad（启动台），反正他从来都没真的好用过

5种视图，全部一屏到底

不需要一个个去点击文件夹，也不再需要翻页——只是找一个应用而已，不值得像过去那样翻山越水。

5 种视图模式

  • 平铺
  • 无色容器
  • 彩色容器
  • 无色网格
  • 彩色网格
快捷唤起 Option + Shift + Space

基于标签的管理

  • 再也不用纠结究竟该属于哪个文件夹——一个应用可以同时归类至多个标签。
  • 支持多色：标签体系自定义颜色
  • 拖拽式操作：拖到标签名或容器即可归类，拖到空隙就是移除分类

为什么不只是 Launchpad？

Launchpad TagLauncher
浏览 分页翻屏，要找图标得记住在第几页 可滚动的应用网格，连续浏览
归类 主要靠文件夹，一个 App 通常只能进一个文件夹 多标签：同一 App 可同时属于「设计」「办公」等
备忘 难以为单个 App 记录用途说明 应用用途备忘，Quick Search 可搜索
备份 布局难导出、迁移、恢复 设置 → 数据：导出 / 导入 JSON

核心功能

App Grid Option+Shift+Space 打开全屏友好的应用网格。
Quick Search 搜索应用名、标签与备忘。
标签体系 自定义颜色；拖拽图标到标签名即可归类。
应用备忘 悬停或编辑用途说明。
布局备份 JSON 导出 / 导入，换机可恢复。
本地优先 数据存于本机，无分析 SDK。
