用标签，而不是文件夹，整理你的 Mac 应用

为什么不只是 Launchpad？

Launchpad TagLauncher
浏览 分页翻屏，要找图标得记住在第几页 可滚动的应用网格，连续浏览
归类 主要靠文件夹，一个 App 通常只能进一个文件夹 多标签：同一 App 可同时属于「设计」「办公」等
备忘 难以为单个 App 记录用途说明 应用用途备忘，Quick Search 可搜索
备份 布局难导出、迁移、恢复 设置 → 数据：导出 / 导入 JSON

核心功能

App Grid Option+Shift+Space 打开全屏友好的应用网格。
Quick Search 搜索应用名、标签与备忘。
标签体系 自定义颜色；拖拽图标到标签名即可归类。
应用备忘 悬停或编辑用途说明。
布局备份 JSON 导出 / 导入，换机可恢复。
本地优先 数据存于本机，无分析 SDK。
